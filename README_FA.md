## گفتار چیست؟

**گفتار** (به معنای «صحبت کردن، گفتمان، گفتگو») یک پلتفرم انجمن سبک و خودمیزبان است که با PHP و SQLite ساخته شده — و از همان ابتدا برای انجمن‌هایی طراحی شده که به زبان‌های RTL مثل فارسی، عربی و اردو صحبت می‌کنند. این سیستم بدون نیاز به هیچ دیتابیس خارجی، یک تجربه کاربری مدرن ارائه می‌دهد و روی هر هاست اشتراکی یا VPS به راحتی نصب می‌شود.

### چرا گفتار؟

- **بدون MySQL** — فقط با یک فایل SQLite کار می‌کند
- **طراحی RTL در اولویت** — کل رابط کاربری با پشتیبانی دوسویه با CSS logical properties ساخته شده
- **واقعاً سبک** — بدون فریمورک سنگین، بدون Composer، بدون Node.js. فقط آپلود و اجرا
- **پر از امکانات** — نظرسنجی، محتوای قفل‌دار، گالری، سیستم NSFW، صفحات ایستا، آپلود فایل با مدیریت سهمیه و پنل مدیریت قدرتمند

## نیازمندی‌ها

| نیاز | حداقل | توصیه‌شده |
|-----|--------|----------|
| PHP | 7.4 | 8.1+ |
| افزونه‌های PHP | `sqlite3`، `gd`، `mbstring` | `sqlite3`، `gd`، `mbstring`، `openssl`، `curl` |
| سرور وب | Apache (با `mod_rewrite`) یا Nginx | Apache 2.4+ |
| فضای دیسک | ~20 مگابایت | ~50 مگابایت (با آپلودها) |
| دسترسی‌ها | دسترسی نوشتن در `storage/` و `config/` | — |

> **هاست اشتراکی؟** گفتار روی هاست اشتراکی عالی کار می‌کند. بدون MySQL، بدون Composer، بدون پیکربندی خاص سرور.

## نصب سریع

### مرحله ۱ — دانلود و آپلود

آخرین نسخه را از [ریلیزها](https://github.com/abdulhalim/Goftar/releases) دانلود کنید و تمام فایل‌ها را در مسیر هاست خود (مثلاً `public_html` یا `htdocs`) آپلود کنید.

### مرحله ۲ — تنظیم دسترسی‌ها

مطمئن شوید سرور وب بتواند در پوشه‌های storage و config بنویسد:

```bash
chmod -R 755 storage/
chmod -R 755 config/
```

### مرحله ۳ — اجرای نصب‌کننده

آدرس سایت خود را در مرورگر باز کنید. به‌طور خودکار به صفحه نصب‌کننده چندزبانه هدایت می‌شوید. نصب‌کننده موارد زیر را انجام می‌دهد:

1. **بررسی نیازمندی‌های سرور** — تأیید نسخه PHP و افزونه‌های مورد نیاز
2. **پیکربندی سایت** — وارد کردن عنوان سایت، شعار و آدرس
3. **حساب مدیر** — ساخت نام کاربری، نام نمایشی و رمز عبور مدیر
4. **سؤالات امنیتی** — تنظیم سؤالات بازیابی رمز عبور
5. **بررسی و نصب** — تأیید تنظیمات و کلیک روی Install

نصب‌کننده به‌طور خودکار دیتابیس SQLite را می‌سازد و پس از اتمام غیرفعال می‌شود.

### مرحله ۴ — شروع استفاده

پس از نصب، با حساب مدیر وارد شوید، به پنل مدیریت بروید، اولین دسته‌بندی خود را بسازید و شروع به ساخت موضوع کنید.

## اولین قدم‌ها بعد از نصب

### ساخت اولین دسته‌بندی

1. با حساب مدیر وارد انجمن شوید
2. روی نام کاربری خود در گوشه بالا-راست کلیک کنید
3. **پنل مدیریت** را از منوی کشویی انتخاب کنید
4. در پنل مدیریت، به بخش **مدیریت دسته‌بندی‌ها** بروید
5. روی **افزودن دسته‌بندی جدید** کلیک کنید
6. نام دسته‌بندی، توضیحات، آیکون و رنگ را وارد کنید
7. روی **ذخیره** کلیک کنید

دسته‌بندی جدید شما حالا در صفحه اصلی انجمن نمایش داده می‌شود.

### ساخت اولین موضوع

1. به صفحه اصلی انجمن بروید
2. روی دسته‌بندی‌ای که ساختید کلیک کنید
3. روی دکمه **موضوع جدید** کلیک کنید
4. عنوان موضوع را وارد کنید
5. محتوای خود را با ویرایشگر Markdown بنویسید
6. به‌اختیاری نظرسنجی اضافه کنید، فایل پیوست کنید یا تصویر درج کنید
7. روی **ارسال** کلیک کنید

موضوع شما الان فعال و برای همه کاربران قابل مشاهده است!
