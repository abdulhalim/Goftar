اگر به دنبال راه‌اندازی یک **انجمن گفتگوی حرفه‌ای** با ظاهری مدرن، امنیت بالا و پشتیبانی کامل از زبان‌های راست‌به‌چپ (RTL) هستید، **گفتار** دقیقاً برای شما ساخته شده است.

> **یک انجمن‌ساز کامل، سبک و قدرتمند** که امنیت، سرعت و تجربه کاربری را در اولویت قرار می‌دهد.

## ✨ ویژگی‌های کلیدی

- **🛡️ امنیت سازمانی**: WAF، محدودیت نرخ درخواست، CSRF، 2FA، مسدودسازی IP
- **🌐 پشتیبانی عالی از RTL و زبان‌های راست‌به‌چپ**: طراحی شده برای فارسی، عربی، اردو و دیگر زبان‌های راست‌چین
- **📋 چندزبانه بودن هسته**: فایل‌های زبان مجزا (فارسی، انگلیسی و قابل توسعه)
- **🚀 نصب آسان**: نصب‌کننده چندزبانه، بررسی خودکار پیش‌نیازها
- **📱 ظاهر مدرن و ریسپانسیو**: تم دارک/لایت، ۱۲ رنگ قابل انتخاب، Font Awesome 6
- **👑 پنل مدیریت حرفه‌ای**: داشبورد تحلیلی، مدیریت کاربران و تاپیک‌ها، سیستم پشتیبان‌گیری
- **💬 امکانات کامل**: پیام خصوصی، محتوای پنهان شرطی، گالری تصاویر، مارکدون

## 🧱 معماری فنی

| ویژگی | توضیح |
|-------|-------|
| **زبان** | PHP 7.4+ |
| **دیتابیس** | SQLite (بدون نیاز به MySQL) |
| **سبک بودن** | فقط یک فایل `.sqlite` |
| **API** | endpoints مجزا برای عملیات اصلی |

## 🔧 پیش‌نیازهای سریع

- PHP 7.4 یا بالاتر
- اکستنشن‌های `sqlite3` و `gd`
